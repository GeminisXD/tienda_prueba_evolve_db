# Frontend de Evolve Store

Aplicación React + TypeScript con Vite y Tailwind CSS 4.

```bash
npm install
npm run dev      # desarrollo en http://localhost:5173
npm run build    # comprobación de tipos + build de producción
npm run lint     # oxlint
```

La documentación completa del proyecto (arranque, variables de entorno, Stripe) está en el [README de la raíz](../README.md).
